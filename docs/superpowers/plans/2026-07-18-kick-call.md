# FreeSBC — Kick-Call Implementation Plan (`DELETE /api/calls/{id}`)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** An operator can tear down a live call by Call-ID (`DELETE /api/calls/{id}` → BYE both legs), via a bridge teardown-by-Call-ID mechanism that reuses the existing race-handled teardown.

**Architecture:** A per-call `killCtx` (a `context.WithCancel`) registered by Call-ID in a mutex-guarded map on `sig.Server`; a fourth `select` case in `onInvite` observes `killCtx.Done()` and BYEs both legs (a `byeBoth` helper shared with the `sess.Done()` case); `Server.KillCall(id)` cancels it. Admin exposes `DELETE /api/calls/{id}` (204/404) via a new `Deps.KillCall` closure.

**Tech Stack:** Go stdlib (`context`, `sync`, `net/http` 1.22 method+wildcard patterns). No new dependency.

## Global Constraints

- **Reuse the existing teardown.** The kick path BYEs both legs via the same `byeContext()`-bounded `Bye` the `sess.Done()` case uses — no new/un-reviewed teardown code. (spec §1)
- **Idempotent + race-safe.** `context.CancelFunc` is idempotent/thread-safe; the killers map is mutex-guarded; `select` fires once. A kick racing a natural end is safe. (spec §1)
- **`DELETE /api/calls/{id}`** behind the M7.1 bcrypt auth: 204 if killed, 404 if unknown. `id` = the A-leg Call-ID (as `/api/calls` lists). (spec §3)
- `admin` still imports only config + callstate + prometheus + stdlib + bcrypt. English identifiers/comments; `gofmt -l .` clean; gate `go test ./... -race` (known M5 SRTP flake aside — if it's the only failure, re-run it).

## Verified facts
- `sig/b2bua.go` onInvite: after bridging, `registry.Add(call)` (call.ID = `callID(req)`, A-leg Call-ID) / `defer Remove`; then `select { case <-aLeg.Context().Done(): bLeg.Bye; case <-bLeg.Context().Done(): aLeg.Bye; case <-sess.Done(): aLeg.Bye + bLeg.Bye }` (b2bua.go:329-349). `byeContext()` bounds a BYE to 5s.
- `sig.Server` built in `NewServer(store, pool, log)`; holds `registry *callstate.Registry`; has `ActiveCalls() int`, `Calls() []callstate.Call`.
- admin `Deps` (admin/server.go) + `main` builds it. `DELETE /api/calls/{id}` — Go 1.25 ServeMux method+wildcard patterns + `r.PathValue("id")`.
- Bridge test harness: `startServer(t, port, cfg)`, `startStubCarrier(t, addr, sdp)` (has `offers` and `byeDone` channels), a UAC via sipgo (see `TestBridgePlacesCallAndBridges` / `TestBridgeFailoverToSecondTarget`), `waitForActiveCalls(t, srv, want, timeout)`.

```go
// in the Server struct:
	killMu  sync.Mutex
	killers map[string]context.CancelFunc // Call-ID → cancel its killCtx

// in NewServer's returned &Server{...}:
	killers: make(map[string]context.CancelFunc),

// methods:
func (s *Server) registerKiller(id string, cancel context.CancelFunc) {
	s.killMu.Lock()
	s.killers[id] = cancel
	s.killMu.Unlock()
}

func (s *Server) unregisterKiller(id string) {
	s.killMu.Lock()
	delete(s.killers, id)
	s.killMu.Unlock()
}

// KillCall tears down the live call with the given A-leg Call-ID by cancelling
// its kill context (the onInvite goroutine then BYEs both legs via the normal
// teardown). Returns false if no such active call is tracked. Idempotent.
func (s *Server) KillCall(id string) bool {
	s.killMu.Lock()
	cancel, ok := s.killers[id]
	s.killMu.Unlock()
	if ok {
		cancel()
	}
	return ok
}
```

```go
// byeBoth sends an independently-5s-bounded teardown BYE to each leg (each Bye
// gets its own byeContext so a slow first Bye can't eat the second's budget).
func (b *bridge) byeBoth(aLeg *sipgo.DialogServerSession, bLeg *sipgo.DialogClientSession) {
	aByeCtx, aCancel := byeContext()
	_ = aLeg.Bye(aByeCtx)
	aCancel()
	bByeCtx, bCancel := byeContext()
	_ = bLeg.Bye(bByeCtx)
	bCancel()
}
```

## Notes for the implementer

- **Reuse the teardown.** The kill case calls `byeBoth` — the SAME BYE path as `sess.Done()`; do not invent a new teardown. `byeBoth` is a refactor of the existing `sess.Done()` body (verify the existing test suite still passes).
- **Race-safety.** `killCancel` is idempotent; the `select` fires once; a kick racing a caller-hangup BYEs the right legs on whichever case wins. Register the killer right after `registry.Add` and unregister/cancel in defers.
- **Call-ID = the A-leg Call-ID** (`call.ID`), which is what `/api/calls` lists as `id` and what `KillCall`/the DELETE route key on. `r.PathValue("id")` URL-decodes the segment (so `abc%40host` → `abc@host`).
- **Deferred:** bulk/by-peer kick, a SIP cause in the BYE, a WebUI kick button (trivial follow-on), graceful delayed kick.
